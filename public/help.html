攔詞虎 WordTiger · 操作說明

從第一個生詞開始。

在英文網頁裡查懂生詞，連同語境收藏，再用間隔複習記住。

高亮與收藏不需要 AI。查詞與拆句需要你自己的 API 金鑰，費用依所選服務方案計算。已有詞典材料的卡片可離線複習。

三步開始

  1. 設定 AI。從工具列開啟攔詞虎設定，填入可信任服務的 Base URL、API Key 和可使用的 Model，按「測試 AI 連線」。預設網址為 https://api.openai.com/v1，也支援相容 Chat Completions 的服務。測試會送出一次可能計費的短請求。
  2. 打開一篇英文文章。點小虎懸浮球、工具列入口或按 Alt+U 開啟生詞標示。亮太多可到設定調高詞頻門檻。
  3. 查詞、收藏、再複習。滑鼠移到單字按 A。預設會先出猜題，可作答或依卡片提示跳過；按 Space 收藏。到「今晚打老虎」，先回想、看答案，再選「記得／忘了」。

常用操作

在啟用標示的文章中使用；文字輸入欄位內不觸發查詞快捷鍵。
按鍵用途
Alt+U開關目前頁面的生詞標示
A查詢滑鼠所在的字
S / D快速看懂句意／拆懂句型
F朗讀單字或卡片原句
Space收藏或取消收藏卡片中的單字／片語

Esc關閉卡片

常見問題

沒有 API 金鑰，可以用嗎？

可以高亮與收藏。新查詞、句意說明與拆句需要金鑰；複習只使用已儲存的詞典內容。新收藏如果尚未查詞，請到「我的攔路虎」按「查一次詞」。片語還需要來源語境。

AI 費用與模型怎麼選？

請依你所選服務的方案確認費用與可用模型。攔詞虎不附贈 API 額度，模型選單也不保證帳號擁有使用權；可以手動填入模型名稱。文字模型可用不代表服務支援 AI 語音，不支援時會改用系統語音。

連線測試失敗怎麼辦？

401：檢查金鑰。403：確認帳號或模型權限。404：確認網址與模型名稱，Base URL 不要包含 /chat/completions。429：確認額度或稍後重試。逾時：檢查網路及端點。其他錯誤請確認服務相容 Chat Completions。

為什麼某些頁面沒有標示？

請先啟用高亮並確認網站不在排除清單。瀏覽器內建頁、擴充功能商店及部分受保護頁面不能注入；PDF、圖片文字與特殊編輯器不保證支援。快捷鍵衝突時，可使用工具列或小虎入口；瀏覽器命令可在 edge://extensions/shortcuts 調整。

我的文章和資料會傳去哪裡？

一般高亮在本機完成。AI 操作可能送出單字、目標句、前一句、頁面標題及你填的背景至你設定的端點；選用同步則傳到自己的 Supabase 專案。詳見隱私政策。

一定要設定 Supabase 嗎？

不用。同步是進階選項，單一裝置使用不需要帳號或資料庫。若要同步，依專案 README 建立自己的 Supabase 專案，執行完整 schema 後，再展開設定頁的同步區登入。

怎麼備份或換電腦？

詞庫可匯出 JSON，內容包含單字、語境與作答紀錄，不包含金鑰或詞典快取，目前沒有匯入還原功能。跨裝置可選用自己的 Supabase 同步。請勿把「匯出 JSON」當成可完整復原的備份；卸載前先確認資料保存方式。

如何排除網站或刪除資料？

在設定加入網域後，請重新整理已開啟高亮的頁面。排除不會移除舊收藏或撤回先前請求。詞庫可刪除收藏；卸載清除本機資料，已同步資料與匯出檔需另行處理。

AI 說明可能出錯，重要用法請再核對原文與可靠詞典。

隱私政策 · 問題回報

回報請附瀏覽器版本與重現步驟，不要附 API 金鑰或私人文章。
