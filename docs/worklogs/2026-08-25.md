## 今日結果

瀏覽器英文學習擴充的核心 MVP 已可從工具列控制、依個人程度分色、串流顯示 AI 回答，
並在設定頁查看生詞語境與查詞快取。整體完成度估計約 85%。

## 完成項目

- 新增工具列 popup：開關目前分頁、逐站自動標示、顏色設定、快捷鍵說明及設定頁入口。
- AI 設定改為 OpenAI base URL 與 model 下拉選單，保留 API key；提供適合快速翻譯與查詞的小型模型。
- 詞頻門檻改為使用者程度：門檻以下不標示，以上依 `1.5 倍`、`2.5 倍`切成三層；手動收藏的生詞使用第四種獨立顏色。
- 查詞、翻譯與文法分析改用 SSE 串流，卡片收到文字就立即更新；完成後才寫入快取。
- 預設查詞 prompt 大幅精簡，只保留音標、語境義項、搭配、雙語例句與必要的易混淆詞；可辨認的舊版長 prompt 會自動遷移。
- 設定頁加入「生詞語境」與「快取回答」分頁；可查看 AI 詞典內容、模型、時間、原文語境及按需翻譯，也可搜尋或刪除查詞快取。
- options 刪除單字時同步軟刪除其語境；查詞快取記錄產生模型。
- 修正整句定位：依滑鼠在文字節點內的位置抽出真正所在句子，而不是整段文字。
- 支援動態頁面：DOM 改變後以 300ms 防抖重新掃描標示。

## 已確認的行為

- 按 `A` 只查詞，不會加入生詞語境。
- 卡片開啟時按 `Space` 加入生詞，才儲存當下句子；少於 26 字元不存，每字最多 5 筆。
- 以程度 8,000 為例：1–8,000 不標示，8,001–12,000、12,001–20,000、20,001 以外分成三層。
- 手動收藏永遠優先於自動詞頻判定；取消收藏後回到詞頻判定。
