# 2026-08-25 作業紀錄

## 今日結果

產品已從「把生詞標出來」往「幫使用者快速讀懂、拆懂並帶走句型」推進。
同時降低技術文章的高亮雜訊、取消無效 AI 請求，並完成同帳號 AI 詞典 cache 同步程式。

## 閱讀與高亮

- 詞頻表外的網址、品牌名與領域術語不再自動高亮，減少 `http`、`github` 及技術專名干擾。
- 四層高亮可分別設定背景、字體與下劃線顏色；舊預設自動遷移，自訂值保留。
- `X` 可將滑鼠下或卡片中的單字標為已認得，不需 AI。
- 並列連詞使用點線、從句連詞使用雙線，可在 popup 或 options 關閉。

## AI 閱讀教練

- `S` 由「整句翻譯」改為「快速看懂」：回答「意思｜」，只在真正容易誤讀時補「關鍵｜」。
- `D` 由「文法分析」改為「拆懂這句」：以「意思｜」「拆法｜」為主，視需要加入卡點、白話英文或可套用句型。
- 兩者都傳入游標焦點詞、同段落前一句與頁面標題，但只分析目標句。
- 句子 cache 納入模型、個人背景、prompt 與上下文，避免舊回答或不同焦點互相覆蓋。
- `D` 回覆「帶走｜英文片語或句型｜提示」時，按 `Space` 可收藏片語與來源語境；沿用現有 `words` / `contexts`，不增加 AI 請求或資料表。
- 關閉卡片、切換查詢、停用或離開頁面時，會從 `runtime.Port` 一路取消到 AI HTTP `fetch`，減少無效 token。

## 詞庫與同步

- 詞庫頁改為「生詞與片語」，保留排序、搜尋、狀態篩選、AI 詞典、逐句翻譯與 JSON 匯出。
- 語境不設筆數上限；相同單字、句子與 URL 精確去重。片語的短來源句仍會保留。
- Supabase local-first 同步程式已加入 `lookup_cache`：同帳號裝置可共用 AI 詞典，清除操作以 tombstone 同步。
- 切換帳號時不會把舊帳號的 AI 詞典 cache 上傳到新帳號；RLS 繼續以 `user_id` 隔離。
- AI Key、prompt、顏色與句子翻譯／拆句 cache 仍僅存本機。
