# 2026-08-25 作業紀錄

## 今日結果

瀏覽器英文學習擴充的本地核心流程已可日常使用，並已由使用者在 Edge 實機確認。
今天完成個人化高亮、DevOps 技術英文輸出、生詞語境保留，以及 Supabase 多裝置同步。

## 完成項目

- 新增工具列 popup：控制目前分頁、逐站自動標示、高亮樣式、快捷鍵與設定頁入口。
- 新增 `X` 快捷鍵：不查 AI 就能把 `timestamp`、`query`、`API` 等已熟悉工作詞標成 `known`；再次按下恢復詞頻判定。
- 查詞、翻譯與文法 prompt 改以專業英文老師、非母語 DevOps 工程師及 AWS／Google Cloud 公開文件語境為準；保留精簡輸出與使用者自訂能力。
- 可辨認的舊版預設 prompt 自動升級，新版不覆蓋使用者自行編寫的內容。
- 生詞語境頁改為卡片式完整列表，支援最近／字母排序、狀態篩選、AI 詞典、逐句翻譯與 JSON 匯出。
- 取消每字 5 筆語境上限；相同單字、句子與 URL 精確去重，保留不同來源的相同句子。
- 四層高亮可分別設定背景、字體與下劃線顏色；舊預設自動換成淡紅、淡橙、淡青、淡灰配色，自訂背景則保留。
- 色盤只改 RGB 並保留既有 alpha，避免 Edge 對 8 位 HEX 色值支援不一致時把透明色重設。
- 詞頻門檻滑桿改為每次調整 2,000 名。
- 新增連詞標記：並列連詞使用點線，從句連詞使用雙線，可在 popup 或 options 關閉。
- 關閉 Vite `modulePreload`，移除 Edge 擴充頁面的 cross-world preload 警告。
- README 與功能設計同步更新；新增 ADR-0007、ADR-0008。
- 新增 Supabase schema：`words`、`contexts`、RLS policy、更新時間 trigger 與同步時間函式。
- 完成 email/password 登入、token refresh、登出及 publishable／legacy anon key 連線。
- 同步採 local-first：舊資料與本機修改以 `pending` 標記，增量拉取使用伺服器 cutoff，衝突採 last-write-wins。
- 軟刪除 tombstone 會跨裝置傳遞；推送途中若本機又被修改，不會被較舊的伺服器回應覆蓋。
- 初次同步每頁拉取 1,000 筆、每批推送 500 筆，避免 Supabase API 分頁上限造成漏資料。
- 新增每 5 分鐘自動同步、本機變更後 30 秒同步、手動同步與失敗 badge。
- options 頁加入同步登入面板，並重整設定、詞庫卡片與小螢幕版面。
- 查詞卡片改為 viewport-safe 固定定位，加入明暗配色、loading、關閉按鈕、快捷鍵標籤及 reduced-motion。
- README 補上 Supabase 建置與登入步驟；新增 ADR-0009。

## 已確認的行為

- 按 `A` 只查詞；按 `Space` 收藏生詞時才保存語境。
- `unknown` 永遠高亮，`known` 永遠不高亮；取消人工狀態後回到詞頻判定。
- 語境少於 26 字元不保存，同一頁的相同句子不重複，筆數不設上限。
- 顏色與連詞設定會在下次開啟頁面標示時套用。
- Edge 實機測試通過；popup、頁面高亮與新增設定可正常使用。
- 使用者已完成 Supabase 專案設定並從擴充功能成功登入。
- Supabase 只同步單字與語境；AI Key、prompt、顏色與本地回答快取不會上傳。
