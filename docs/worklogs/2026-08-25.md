# 2026-08-25 作業紀錄

## 今日結果

產品已從「把生詞標出來」往「幫使用者快速讀懂、拆懂並帶走句型」推進。
同時降低技術文章的高亮雜訊、取消無效 AI 請求，完成同帳號 AI 詞典 cache 同步，
並將專案正式品牌化為「攔詞虎 WordTiger by JasonDevOps」。Chrome／Edge 與 Safari MV3
都已能產出含正式 icon 的 production build。

## 閱讀與高亮

- 詞頻表外的網址、品牌名與領域術語不再自動高亮，減少 `http`、`github` 及技術專名干擾。
- 四層高亮可分別設定背景、字體與下劃線顏色；舊預設自動遷移，自訂值保留。
- `X` 可將滑鼠下或卡片中的單字標為已認得，不需 AI。
- 並列連詞使用點線、從句連詞使用雙線，可在 popup 或 options 關閉。
- 連詞表改為專案自己的常見句子骨架集合；`yet` 納入並列連詞，`with` 不再誤標。

## AI 閱讀教練

- `S` 由「整句翻譯」改為「快速看懂」：回答「意思｜」，只在真正容易誤讀時補「關鍵｜」。
- `D` 由「文法分析」改為「拆懂這句」：以「意思｜」「拆法｜」為主，視需要加入卡點、白話英文或可套用句型。
- 兩者都傳入游標焦點詞、同段落前一句與頁面標題，但只分析目標句。
- 句子 cache 納入模型、個人背景、prompt 與上下文，避免舊回答或不同焦點互相覆蓋。
- `D` 回覆「帶走｜英文片語或句型｜提示」時，按 `Space` 可收藏片語與來源語境；沿用現有 `words` / `contexts`，不增加 AI 請求或資料表。
- 關閉卡片、切換查詢、停用或離開頁面時，會從 `runtime.Port` 一路取消到 AI HTTP `fetch`，減少無效 token。

## 詞庫與同步

- 詞庫頁改為「生詞與片語」，保留排序、搜尋、狀態篩選、AI 詞典、逐句翻譯與 JSON 匯出。
- 語境不設筆數上限；相同單字、句子與 URL 精確去重。片語的短來源句仍會保留。
- Supabase local-first 同步程式已加入 `lookup_cache`：同帳號裝置可共用 AI 詞典，清除操作以 tombstone 同步。
- 切換帳號時不會把舊帳號的 AI 詞典 cache 上傳到新帳號；RLS 繼續以 `user_id` 隔離。
- AI Key、prompt、顏色與句子翻譯／拆句 cache 仍僅存本機。

## 品牌化與介面

- 正式名稱定為「攔詞虎」，英文名稱 `WordTiger`，開發者識別 `JasonDevOps`，標語為
  「把英文裡的攔路虎，一隻隻抓起來。」
- manifest、options、popup、README、package metadata、console 標記、CSS Highlight 名稱、
  `runtime.Port` 與 alarm 全部統一為 WordTiger。
- 現行原始碼、文件與 build 產物已移除參考產品識別、舊商店 ID、舊內部前綴與比較性敘述；
  同時清除忽略目錄中的舊 Safari MV2 與舊名 ZIP；未重寫 Git 歷史。
- 以內建 imagegen 產生「友善老虎撲住青色螢光筆」的原創母圖，並從同一母圖產生
  16、32、48、128、300 與 1024px 資產。
- popup 與 options 顯示正式 icon。閱讀卡片只在標題列顯示 28px icon，並標示為裝飾性圖片；
  未互動時靜止，游標移入會打招呼、拖曳按下會壓縮；AI 載入中做明顯蹲跳，完成、收藏
  或設為認得時播放一次撲抓與落地。
- 閱讀卡片改為依序評估右、左、下、上空間，同一次 AI 串流固定方向並限制正文高度，
  避免長回答蓋住原字；標題列可用 Pointer Events 直接拖曳，靠近左右邊緣會平順貼齊。
- 卡片加入橘色到青色的細頂光，並支援 `prefers-reduced-motion` 與
  `prefers-reduced-transparency`，不新增動畫依賴。
- IndexedDB 改名為 `wordtiger`，資料庫 class 改為 `WordTigerDb`，JSON 匯出檔改用 `wordtiger-` 前綴。
  目前只有單一測試使用者，因此不寫 legacy 搬移；舊測試資料會在新版中重置。
- 新增 [ADR-0010](../adr/0010-wordtiger-brand-and-restrained-mascot.md)，固定品牌名稱、資產來源與卡片的克制使用原則。

   避讓、長回答捲動、標題列拖曳、貼邊與 reduced-motion，確保不擋原字。
3. 在 Supabase SQL Editor 重新執行 `supabase/schema.sql`，建立 `lookup_cache`、trigger 與 RLS policy。
4. 重新載入擴充功能，裝置 A 按「立即同步」，再於裝置 B 同步，確認「生詞與片語」可直接打開已查過的 AI 詞典。

6. 實際試讀數篇技術文章，檢查 `S` / `D` 回答是否值得閱讀，以及「帶走」片語是否值得收藏。
