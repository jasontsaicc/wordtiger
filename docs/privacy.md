# 攔詞虎 WordTiger 隱私權政策

最後更新：2026-09-18

## 適用範圍與摘要

本政策適用於 Microsoft Edge 上的攔詞虎擴充功能。攔詞虎採本機優先設計，開發者不經營接收學習資料的伺服器，也沒有內建廣告、分析、遙測或自動錯誤回報。

你選用 AI 或跨裝置同步時，相關資料會傳送至你設定的服務。這些服務有各自的隱私與保留政策；開發者不會透過攔詞虎取得你的金鑰、查詢內容或學習紀錄。

## 留在瀏覽器的資料

資料儲存在瀏覽器本機的 IndexedDB 與擴充功能儲存區：

- 收藏與排除的單字、片語、來源句子、來源網址及標題。
- AI 查詞結果、句意與拆句快取；查詢即使沒有收藏，也可能留下快取。
- 複習排程、複習成績與查詞猜題紀錄。
- AI 服務網址、API 金鑰、模型、你填寫的背景與自訂提示詞。
- 詞頻門檻、配色、網站排除清單與自動標示設定。
- 啟用同步時的 Supabase 專案設定、登入 email 與工作階段憑證。

詞頻表隨擴充功能提供。掃描文字及生詞高亮在本機完成，不需向 AI 傳送整篇網頁。攔詞虎不建立一般瀏覽歷史紀錄；學習足跡來自收藏、語境及作答資料。

## 送往你設定的 AI 服務

查詞、句意說明、拆句與 AI 語音使用你設定的 Base URL。API 金鑰會透過 Authorization 標頭送給該服務，請只設定你信任的端點。AI 回應和資料保留方式受該服務政策約束。

以下使用者操作可能觸發請求；有效快取可避免部分文字請求：

- **查詞**：按 A、在詞庫按「查一次詞／重查」，或收藏拆句卡中的片語後建立詞典。送出單字或片語、實際字形、來源句子、你填寫的背景，以及對應提示詞。
- **快速看懂與拆句**：按 S／D 或在卡片重試。送出目標句、游標所在詞、同段落前一句（最多 300 字元）、頁面標題（最多 200 字元）、你填寫的背景與提示詞。YouTube 語境可能使用當前字幕。
- **朗讀**：按 F 或複習頁的朗讀按鈕。送出要朗讀的單字或句子，以及固定語音指示。AI 語音不可用時，會改用瀏覽器或裝置提供的語音；語音是否需要連線取決於所選系統語音服務。
- **測試 AI 連線**：按設定頁測試按鈕，送出固定的短測試文字及所選模型，不包含網頁內容、個人背景或自訂提示詞。測試也可能產生服務費用。

文字請求送往 Base URL 下的 /chat/completions；AI 語音送往 /audio/speech。一般背景掃描不會自動查詞，但收藏片語可接續觸發上述詞典建立請求。

## 同步到你的 Supabase 專案（選用）

跨裝置同步預設未啟用。你必須自行建立 Supabase 專案並登入，才會開始定期同步及操作後的增量同步。登入會把 email 與密碼送至該專案的驗證服務；本機保留工作階段憑證，不保留登入密碼。

同步包含五張表：

- **words**：單字、收藏狀態與複習排程。
- **contexts**：來源句子、網址與標題。
- **lookup_cache**：AI 查詞結果。
- **review_log**：複習作答紀錄。
- **quiz_log**：查詞猜題的選項、答案與作答紀錄。

AI 金鑰、AI 端點、使用者背景、自訂提示詞、配色、網站排除設定及句意／拆句快取不作為設定欄位上傳。但 AI 回答本身可能引用背景或語境，而查詞回答會隨 lookup_cache 同步。

資料位於你設定的專案。你與該專案的管理者依專案權限管理資料，開發者不會因你啟用此功能而取得權限。

## 你的控制權與資料保留

- **停止 AI 請求**：清空 API Key。高亮與收藏仍可使用；已有詞典材料的卡片可離線複習。尚未查詞的新收藏不會成為複習題目。
- **停止同步**：在同步區登出。本機與已同步資料不會因此被刪除。
- **排除網站**：在設定加入網域，阻止之後透過一般啟動路徑開啟該網站的高亮。若頁面已啟用，新增排除後請重新整理頁面。這不會刪除先前收藏、取消已送出的請求，或阻止你在詞庫中手動查詢已保存的內容。
- **查看與匯出**：「我的攔路虎」與「老虎足跡」可查看學習資料；JSON 匯出包含單字、語境與作答紀錄，不含 API 金鑰或 AI 詞典快取，目前不提供匯入還原。
- **刪除**：詞庫刪除使用軟刪除標記以支援同步，不等於立即抹除所有底層資料。移除擴充功能會清除該瀏覽器設定檔中的本機資料；你的匯出檔需自行刪除。雲端資料請到自己的 Supabase 專案刪除，重新啟用同步前也應處理其他裝置上的副本。

本機學習資料不設自動到期時間，會保留至你刪除資料或移除擴充功能。AI 服務與 Supabase 的保留期限由各服務及你自己的專案設定決定。

## 權限用途

- **所有網站的主機權限**：提供頁面上的小虎入口、按需注入高亮，並連接你自行指定、無法事先列舉的 AI 與 Supabase 端點。瀏覽器限制的內建頁面不支援。
- **scripting**：透過快捷鍵、工具列、小虎或你啟用的網站自動標示設定，載入高亮程式。
- **storage**：儲存本機設定及同步工作階段。
- **alarms**：安排選用同步的執行時間。

小虎入口本身不發出網路請求。資料傳送情況以本政策的 AI 與同步章節為準。

## 兒童隱私與政策變更

攔詞虎不針對 13 歲以下兒童設計。政策有變更時，會更新本頁日期並記錄於版本變更紀錄。
