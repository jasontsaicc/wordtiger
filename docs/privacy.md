# 攔詞虎 WordTiger 隱私權政策

最後更新：2026-08-30

## 摘要

攔詞虎不經營任何伺服器，也不接收使用者的資料。開發者看不到你查了哪些字、讀了哪些網頁，或你的任何個人資訊。

這份政策適用於在 Microsoft Edge 上安裝的攔詞虎擴充功能。

## 資料的三個去向

### 1. 留在你的瀏覽器

預設情況下，攔詞虎的所有資料都存在瀏覽器本機的 IndexedDB 與擴充功能儲存區，不會離開你的裝置：

- 你收藏的單字與片語
- 單字出現的原句、來源網址與標題
- AI 查詞與拆句的結果快取
- 複習紀錄與排程狀態
- 你的設定，包含 AI 端點網址與 API 金鑰

生詞高亮完全在本機完成。詞頻資料在安裝時就打包在擴充功能裡，判斷哪些字要標示不需要連外。

### 2. 送到你自己設定的 AI 端點

查詞、句意說明、拆句與 AI 朗讀需要你在設定頁自行填入 Base URL、API Key 與模型名稱。這個端點由你選擇，可以是 OpenAI，也可以是任何相容的服務或你自架的服務。攔詞虎不提供、不代理、也不經手這個端點。

只有在你主動按下快捷鍵時，才會送出以下內容：

| 觸發 | 送出的內容 | 送到 |
| :--- | :--- | :--- |
| `A` 查詞 | 單字原形、頁面上的實際字形、該字所在的句子 | `{你的 Base URL}/chat/completions` |
| `S` 快速看懂 | 該句子 | `{你的 Base URL}/chat/completions` |
| `D` 拆懂 | 該句子 | `{你的 Base URL}/chat/completions` |
| `F` 朗讀 | 要唸出來的單字或句子 | `{你的 Base URL}/audio/speech` |

送出的範圍是單字與它所在的那一句，不是整個頁面。攔詞虎不會在背景自動向 AI 端點送出請求，每一次請求都對應你的一次按鍵。

你的 API 金鑰只會送給你自己填的那個端點，用於該端點的驗證。金鑰不會傳給開發者或任何第三方。

你填在黑名單裡的網域不會觸發上述任何請求。

### 3. 同步到你自己的 Supabase 專案（選用）

跨裝置同步預設關閉。若要啟用，你需要自行建立 Supabase 專案、執行本專案提供的 schema，並在設定頁填入該專案的網址與金鑰。資料只在你自己的專案與你的裝置之間流動，開發者沒有存取權。

啟用後會同步這四張資料表：

- `words`：收藏的單字與複習排程狀態
- `contexts`：單字出現的原句、來源網址與標題
- `lookup_cache`：AI 查詞結果的快取
- `review_log`：複習作答紀錄

以下不會上傳，只留在本機：

- AI 端點網址、API 金鑰與自訂 prompt
- 句意說明與拆句的快取（`sentenceCache`）
- 高亮顏色、詞頻門檻與網域黑名單等介面設定

## 不會收集的資料

- 一般瀏覽歷史。學習足跡只根據你主動收藏與複習的紀錄產生。
- 未收藏單字所在的頁面內容。
- 任何形式的分析、遙測或錯誤回報。攔詞虎沒有內建統計工具。
- 廣告識別碼。攔詞虎不含廣告，也不與廣告服務整合。

開發者不販售、不出租、不交換使用者資料，因為開發者從未取得這些資料。

## 你的控制權

- **停止傳送**：不填 AI 設定即可。高亮、收藏與複習在沒有 AI 的情況下照常運作。
- **停止同步**：在設定頁登出即可。本機資料不受影響。
- **排除特定網站**：把網域加入設定頁的黑名單，該網站不會觸發高亮與任何 AI 請求。
- **檢視資料**：設定頁的「我的攔路虎」與「老虎足跡」可以看到所有已儲存的內容。
- **刪除資料**：移除擴充功能會清除全部本機資料。已同步的資料由你在自己的 Supabase 專案中刪除。

## 權限用途

| 權限 | 用途 |
| :--- | :--- |
| `<all_urls>` 主機權限 | 小虎懸浮球需要出現在任何英文頁面上，且 AI 端點與 Supabase 網址由你自訂，無法事先列舉 |
| `scripting` | 你啟動高亮後，才把高亮程式注入當前分頁 |
| `storage` | 儲存你的設定 |
| `alarms` | 排定背景同步的時間 |

擴充功能雖然具備讀取所有網站的權限，但懸浮球本身不連外。只有你啟動高亮並按下快捷鍵時，才會有資料離開裝置。

## 兒童隱私

攔詞虎不針對 13 歲以下兒童設計，也不會刻意收集兒童的個人資訊。
