# ADR-0035: 首次使用先完成查詞，連線測試沿用文字 AI 路徑

Date: 2026-09-19 | Status: accepted

## Context

首次安裝會開啟設定頁，但原先先呈現 Supabase 欄位，容易讓使用者以為同步是必要條件。AI 設定只有欄位，使用者難以確認金鑰、模型或服務網址是否正確。

上架前的優先工作是讓陌生使用者完成第一次查詞，並清楚理解費用與資料傳送，而非增加新的學習模式。

## Decision

- 設定頁頂端顯示三步開始；Supabase 同步收合為進階選項。
- 操作說明及隱私頁隨擴充功能封裝，可離線閱讀。
- 使用者主動點擊連線測試時，先保存設定，再經 background 沿用文字 AI 的 Chat Completions 路徑送出固定短訊息。
- 測試不帶入網頁、個人背景或自訂 prompt，不寫入詞典快取；20 秒逾時，執行時避免重複點擊。
- 檢查網址協定、網址中的帳密、金鑰及模型；呈現常見 HTTP 錯誤指引，不顯示服務端原始錯誤內容。
- 明示測試可能產生 API 費用，且只驗證文字服務，不代表 AI 語音可用。
- 隱私文件依實際操作揭露前一句、標題、背景、收藏片語後查詞、按鈕朗讀及 quiz_log 同步。

## Alternatives

- 另寫一個健康檢查端點：相容服務未必提供，且不能驗證模型實際可生成文字。
- 用真實文章測試：會不必要地傳送網頁內容，改用固定短訊息。
- 首次安裝強制設定同步或帳號：本機優先功能不需要，維持選用。

## Consequences

測試成功代表這次文字請求有效，不保證所有模型輸出品質、語音服務或後續額度。未提供金鑰仍可高亮與收藏；複習需要已有詞典材料，片語另需來源語境。

JSON 匯出仍不是完整備份，沒有匯入還原且不含詞典快取；說明清楚列出限制，還原功能留待後續需求。
