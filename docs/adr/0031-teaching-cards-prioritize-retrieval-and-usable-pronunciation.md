# ADR-0031: 教學卡先教判斷、可用搭配與提取，發音不用整串 KK

Date: 2026-09-05 | Status: accepted; 發音部分 superseded by [ADR-0033](0033-pronunciation-gives-kk-plus-one-action.md)

## Context

按 `A` 的查詞卡已經能依原句解釋詞義、出三選一與提供例句，但 KK 音標和多個延伸欄位
不能直接回答非母語讀者的三個問題：為什麼本句是這個意思、我怎麼自然使用、我能否自己說出來。
`S` 與 `D` 也需要各自清楚的學習分工，不能都變成較長的翻譯。

## Decision

- `A` 以本句判斷線索、核心詞義、可套用搭配、不同情境例句與一個口頭造句任務為主。
- `發音與重音` 取代整串 KK 音標：多音節字標主重音與節奏，只教一個最有幫助的具體發音動作；不確定就省略，不用中文諧音。
- `S` 固定為最多兩行的速讀翻譯，保留條件、否定、語氣與責任歸屬。
- `D` 只解釋一個真正阻礙理解的卡點，引用原句作判斷證據，然後帶走一個可重用表達。

## Alternatives

- **保留 KK 音標作主體**：精確但對多數讀者缺少可操作的發音指引，卡片也更難掃讀。
- **每個字都加字族、詞源與記憶口訣**：容易撐滿卡片，卻犧牲當下理解和提取練習。
- **把 A、S、D 都做成完整教學卡**：重複內容會增加等待與閱讀成本，沒有清楚的快捷鍵分工。

## Consequences

新預設 prompt 使舊的未自訂模板自動遷移；自訂模板不被覆蓋。查詞輸出仍受既有系統層的
三選一與 Markdown 契約約束。生成品質仍要以實際查詞卡抽查，因為發音提示由模型生成，
不可只依 prompt 測試推定正確。
