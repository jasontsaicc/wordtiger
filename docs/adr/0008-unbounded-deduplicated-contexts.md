# ADR-0008: 語境不設筆數上限並做精確去重

Date: 2026-08-25 | Status: accepted

## Context

每字只保留 5 條語境會刪掉較早但仍有學習價值的真實例句。此版本目前是單人、本地使用，
少量文字記錄的儲存成本低於遺失學習歷程的成本。

## Decision

取消每字 5 筆上限。新增語境時，若同一單字已有完全相同的句子與 URL 就不重複寫入；
不同頁面的相同句子仍保留。少於 26 字元的句子與既有軟刪除規則不變。

## Alternatives

- **維持最近 5 筆**：空間固定，但會默默刪除仍有價值的資料。
- **只按句子去重**：不同文件引用相同句子時會失去來源資訊。
- **現在就加複合索引或全域容量管理**：單人資料量尚未需要，會提前增加 migration 與設定成本。

## Consequences

語境頁能呈現完整累積歷程，資料量不再有固定上限。新增時目前會線性掃描該字的語境；
只有實際出現延遲時，才新增 `[word+url]` 索引或容量管理。
