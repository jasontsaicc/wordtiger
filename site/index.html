安裝前，先了解

你可能想知道。

一定要有 AI API 金鑰嗎？

高亮和收藏不需要。新查詞、句意說明與拆句需要自己的金鑰；已有詞典內容的卡片可離線複習。攔詞虎不提供 API 額度，AI 使用費依你選擇的服務方案計算。

網頁內容會傳到哪裡？

一般高亮在本機完成。你使用 AI 時，相關單字、句子、前一句、標題及填寫的背景可能送至你指定的端點。跨裝置同步則使用你自己的 Supabase 專案。詳見隱私政策。

需要註冊帳號或設定同步嗎？

不用。單一裝置的資料保留在本機。跨裝置同步是進階選項，需要自行建立 Supabase 專案；JSON 匯出目前不提供匯入還原，不能當成完整備份。

所有網站都能使用嗎？

以一般英文文字網頁為主。瀏覽器內建頁與部分受保護頁面無法使用；PDF、圖片文字及特殊編輯器不保證支援。可依網域排除不想啟用的網站。

如何回報問題？

請到 GitHub Issues 提供瀏覽器版本與重現步驟。不要附上金鑰、登入憑證或私人文章。AI 解釋可能出錯，重要用法請再核對。
